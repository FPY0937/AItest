# 概要设计评估

## 评估对象

`ai-agent/spec/{需求项编号}/{需求项编号}_概要设计_{短标题}.md`

## 否决项（有一条即不通过）

- [ ] 需求用例未通过，或需求确认不是通过，仍出设计
- [ ] 范围内需求点未映射到模块，或用例中的 UC 既不在模块职责里，也不在「本次不解决」
- [ ] 结构变更把对既有调用方标成破坏，却没有写出取舍
- [ ] 业务需求无主流程，或无失败/补偿说明。技术变更改为：未写版本范围、未写对外行为是否变化、或未写回退
- [ ] 技术变更承认返回、错误、时序或默认配置会变，却未改按结构变更写接口和取舍
- [ ] 写成了字段 schema、类图或方法清单。结构变更里服务不少于 2 个或接口不少于 2 条时，没有与接口表一致的 mermaid，或另附了图片
- [ ] 没有新服务、新调用、同步/异步变化或数据归属变化，却按结构变更新增了系统级接口
- [ ] 发明了应用架构里不存在、且未标待确认的服务
- [ ] 有多块可独立验收的能力，却没有能力地图
- [ ] 新服务、新调用、同步/异步或数据归属没有写出取舍
- [ ] 可单独验收的能力行没有 `intent`，或把仅保存本服务自身数据的数据库写入单独检索
- [ ] `add_capability`、`new_service_or_call`、`replace_capability` 未查阅，且未标成未验证
- [ ] 2 至 20 条命中由代理自行选定，或零命中却写下了组件标识
- [ ] 本阶段调用了 `get_component`、`get_doc_section` 或 `get_sample`，或写了完成方式、版本、文档正文
