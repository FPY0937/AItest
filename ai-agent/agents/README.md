# 智能体索引

流水线：需求 → 概要设计 → 详细设计 → 程序设计 → 编码 → 测试 → 分提。测试设计可在需求确认通过后与后续设计、编码并行。

可复用资产只经 `ai-agent/mcp/glue.md` 查阅。需求、测试设计和测试执行、分提不查阅。地址和令牌不写在本目录。

每个节点都是 `rules/` + `template/agent.md` + `template/eval.md`。分提不是智能体，测试执行完成后按 `ai-agent/skills/delivery/split-submit-skill/skill.md` 把各 `git-repo-*` 中的改动提交到各自远程。尚未检出、暂存在 `work/` 的，分提时再放到目标库。

| 目录 | 说明 |
|---|---|
| [01_需求智能体](01_需求智能体/template/agent.md) | 把一句话诉求写成需求用例 |
| [02_设计智能体/01_概要设计](02_设计智能体/01_概要设计/template/agent.md) | 服务边界、主流程、系统级接口 |
| [02_设计智能体/02_详细设计](02_设计智能体/02_详细设计/template/agent.md) | 子条目的字段、状态、异常码；技术变更只写证明和回退 |
| [02_设计智能体/03_程序设计](02_设计智能体/03_程序设计/template/agent.md) | 一个子条目一个目标库、方法契约、P0 的失败测试 |
| [03_编码智能体](03_编码智能体/template/agent.md) | 在一个子条目的目标库里实现，并留下 P0 的先失败后通过记录 |
| [04_测试智能体](04_测试智能体/template/agent.md) | 按已确认的验收做测试设计和 P0 执行；不写单元测试 |
