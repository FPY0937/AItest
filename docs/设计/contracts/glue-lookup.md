# Contract: glue 查阅

使用方的代理在阶段技能允许的时机调用提供方托管的查阅服务。服务名是 `glue`。业务代码不得调用。阶段包不包含服务进程、目录、程序包、文档、样例或令牌。

地址保持空白，直到人提供。令牌从环境变量 `GLUE_TOKEN` 读取，不得写入仓库。地址缺失、调用失败或版本不一致时，停住这次新服务或新的系统间调用并询问。同一需求里的范围内改动可以继续。

每次调用都产生一条查阅审计，字段见 `data-model.md`。

## search_components

用途：按能力分类，不返回正文，不锁定版本。

允许的调用方：

- 概要设计，且正要写出新服务或新的系统间调用。只查登记索引。
- 详细设计复核时必须带上概要留下的标识。服务按主键过滤，不再做能力匹配。

概要设计得到的每条结果只含：标识、一句话能力、标签、状态。命中数大于 20 时只返回命中数和标签分布。检索步骤、索引字段和这个上限见 [catalog-index.md](./catalog-index.md)。

规则：

- 状态为 `deprecated` 的登记不返回，除非本次需求写明保留该旧资产。
- 恰好一条：概要只记候选绑定。
- 多条：不返回由代理挑选后的结果。调用方必须停住，一次只问一个问题。
- 零条：调用方沿原变更类型继续，不编造资产。
- 详细设计若发现结果与概要候选矛盾，回到概要设计。

## get_component

用途：读取一条登记的全部字段，不含文档正文。

允许的调用方：详细设计、程序设计。

返回字段：标识、一句话能力、标签、发布标识、文档位置模板、样例标记、维护人、状态。

规则：

- 必须指定概要已经记录的标识。这是主键点查。
- 未指定版本时只返回身份和版本号列表。指定版本后才返回八个登记字段和该版本的章节标题。
- 服务不默认选择较新版本。
- 不得用它一次拉取多个候选再比较。
- 技术变更不得用它按能力重新匹配。

## get_doc_section

用途：读取指定版本的一章，作为「既有资产」的证据，或作为编码时对照的章节。

允许的调用方：详细设计、编码。

必须同时提供：资产标识、版本、章节。

拒绝：

- 没有版本。
- 未指定章节。
- 要求取走全部文档。
- 该章对象大于 256 KiB。

一次调用只读取这一个对象。对象键由 [catalog-index.md](./catalog-index.md) 的模板生成，根地址保持空白。

资产名必须来自返回的页面。证据记录文档名称和章节。

## get_sample

用途：取得可复制的样例。

允许的调用方：编码，且程序设计已经锁定版本，人已经确认该版本。

行为：

1. 先返回该版本的文件列表。
2. 再按列表读取文件。

规则：

- 只返回样例自身测试已经通过的版本。
- 样例标记必须与锁定版本一致。
- 样例位置的形式是 `references/<标识>-ref`。标识来自登记，不在契约里预填。
- 编码只把这些文件当作该版本的样例，并只编写版本锁定里记下的差异。

## 调用方禁止事项

- 需求阶段不得调用以上任一动作。
- 概要设计不得调用 `get_component`、`get_doc_section`、`get_sample`。
- 程序设计不得调用 `get_sample`。样例留到编码。
- 测试阶段不得用资产内部测试代替本服务在资产成功和资产失败时的验证。
- 代理不得因查阅成功而签署需求确认或架构师确认。
