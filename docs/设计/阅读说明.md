# 设计文档怎么读

本目录是资产复用方案的设计正文。阶段包在仓库根的 `ai-agent/`，不在这里。

文内若写 `specs/001-asset-reuse-harness/`，改为看本目录下的同名文件。若写 `.specify/memory/constitution.md`，改为看本目录的 `constitution.md`。

## 先读这两份

1. `详细设计.md`：最终设计。总体架构、阶段包边界、意图与检索、四个查阅方法、数据放在哪里。
2. `流程设计.md`：八个阶段各自做什么、留下什么、何时调用查阅。

两份冲突时，以 `详细设计.md` 为准。

## 接着按需要看

| 文件 | 内容 |
|---|---|

## 不要当成事实

目录地址、文档站、样例库、组件标识、查阅地址、确认人、仓库名，设计里没有事实的都保持空白。`panda-test`、`https://123.12.1.21`、`com.example.internal` 只是旧材料里的格式示例。

glue 进程、检索索引、组件程序包、样例正文和令牌不在本仓库。
