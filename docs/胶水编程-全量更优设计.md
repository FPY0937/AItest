### 0.1 用户已拍板（全文默认，不得再议）

| # | 决策 | 实现含义 |

### 2.2 边界

| 界 | 负责 | 不负责 |
|----|------|--------|
| **提供方** | 制品、版本文档、拆章索引、样例发布快照、glue HA、MCP/HTTP、令牌、上架状态机、审计 | 替业务写代码；把全站物料打进业务仓 |
| **使用方** | 装阶段包、写规格/锁定表、出胶水、跑 Gate | 私自拷过期文档/样例树；绕过坐标贴源码；维护本地 index |
| **Agent/IDE** | 按意图门禁调 MCP 四方法；抄发布快照→引 GAV→最小胶水 | 静默改 acceptance；自动升 major；跳过查阅写「无」；用 git 当默认可抄源 |

### 2.3 端到端主链

```
[Owner] Docsify tag（同 commit）+ 发 jar + reference 改动
    → Maven exists 探测 → artifacts_published
    → 拆章 builder → docs_split
    → ref-ci 全绿 → 上传 objects 发布快照 → samples_passed
    → 建 search-index → 原子切换 → indexed_active
    （此时且仅此时 identity 可标 active，见 §5.2）

[使用方] 可选安装器 → 写入 ai-agent/ + glueUrl 占位（无 index）
[Agent] intent 分类 → MCP 四方法 → 锁定表 → get_sample + Maven resolve
[Gate] enforcer + 锁定表 vs resolved 树 + exemption + 未验证依赖
[漂移] 分类后继续或回退阶段
```

失败任一步：**不推进状态 / 不切换索引 / Gate 红 / 停该能力点**——不得静默降级为手写已有能力。

### 2.4 默认数据流（查阅）

```
IDE Agent
  → MCP tool（主入口） / 或 HTTP POST（同 body）
  → Authorization: Bearer <GLUE_TOKEN>
  → 网关：鉴权 · 限流 · callerStage 白名单
  → glue ×N：读共享快照（请求开始时的 volatile 引用）
  → 旁路追加审计
  → JSON 响应（含 glueProtocolVersion）
```

程序包路径：**锁定 gav → 私有 Maven**（凭证与 `GLUE_TOKEN` 分离）。

## 3. 意图与阶段门禁

### 3.1 意图枚举（子项机读必填）

未写 `intent` **不得**进入可查阅阶段（概要及之后的资产相关阶段）。

| intent | 查阅动作 | 人确认 | 失败边界 |
|--------|----------|--------|----------|
| `add_capability` | **必须** `search_components` | 0/1/2–20/>20 同 §3.3 | **停该能力点** |
| `new_service_or_call` | 必须 search | 同上 | 停该能力点 |
| `upgrade_existing` | **不**按能力 search；`get_component(已知 id)`；读 `breaking` / `migrateTo` / 迁移章 | breaking 必人批 + 迁文档 | 停升级点 |
| `replace_capability` | 必须 search + 迁移目标确认 | **禁止**当纯技术变更 | 停替换 |
| `bom_bump` | catalog 内坐标 **diff** → 影响面清单 | 按清单拆升级子项，每项再走 `upgrade_existing` | 无 diff → 人工清单 |
| `in_range_change` | 不 search | — | **不得**用于「拟复用却查阅失败」 |

「新」的判定单位 = **对外可部署服务/进程**，≠ Maven module。仅新增 module 默认不触发 search，除非新暴露接口或 `intent=add_capability`。

### 3.2 阶段 × 方法矩阵（服务端强制）

`callerStage` 白名单；越权返回 `forbidden_stage`。

| 阶段 | search | get_component | get_doc_section | get_sample |
|------|--------|---------------|-----------------|------------|
| 需求 | 否 | 否 | 否 | 否 |
| 概要设计 | 按 intent | 候选 constraints 摘要 | 否 | 否 |
| 详细设计 | 补检索/主键 | 是 | 人指定章 | 否 |
| 程序设计 | 否 | 锁版本 | 迁移章 | 否 |
| 编码 | 否 | 否 | 按锁 | **是** |
| 测试设计/执行 | 否 | 否 | 否 | **仅**已锁 `testSamplePaths` 补拉 |
| 评审/分提 | 否 | 对照锁定（只读技能，非 glue 必调） | 否 | 否 |

阶段切换须**显式命令**；一次会话一个阶段。跨阶段自动停止。

### 3.3 检索四种结果（概要/详设）

`deprecated` 默认不算命中，除非需求写明保留或 `includeDeprecated=true`。

| 命中 | 处理 |
|------|------|
| 恰好 1 | 记 `assetId`，「待详细设计绑定」 |
| 2–20 | **停问人**；代理不得自行挑选；问人卡片带 `constraints` 摘要 |
| >20 | 只返回 `matchCount` + `tagFacets`；先收窄再查 |
| 0 | 可走 `completionMode=implement`；**不得**编造资产；未查阅不得写「无」 |

**必须复用清单**优先于 search 排序；冲突 → 停问人，不得静默覆盖。允许输出「升格建议工单」，**禁止**程序设计回写应用规约。

### 3.4 查阅不可用（落实 D3）

无本地 index。当出现 `missing_token` / 401 / 403 / 超时耗尽 / 5xx 耗尽 / `index_not_ready` / glue 全不可用：

| 范围 | Agent 行为 |
|------|------------|
| 拟 `add` / `replace` / `new_service` / 需查阅的 `upgrade` / `bom_bump` 影响点 | **停止该能力点**；提示人恢复查阅或走豁免流程 |
| 真正无关的 `in_range_change` | 可继续 |
| 若人坚持在不可用期间引入依赖 | 锁定表必须标 `reuseVerification: unverified`；Gate **告警并默认阻断**生产合入（见 §10） |

禁止：猜 API、抄过期本地文档、静默当「范围内」跳过查阅。

### 3.5 需求阶段约束

允许「能力域 / 约束」标签草稿（非 id/GAV）。**禁止**需求写组件 id/GAV。确认只打开下一设计阶段，不打开编码。代理不得签署需求确认或架构师确认。

## 4. 提供方：上架、拆章、索引、HA、鉴权审计

### 4.1 上架状态机

版本级机读状态（仅 CI/发布账号可写）：

```
draft
  → artifacts_published   # Maven exists 探测通过，gav 非空
  → docs_split            # 同 commit 拆章成功，章 contentHash 非空
  → samples_passed        # ref-ci 全绿且已上传 objects 发布快照
  → indexed_active        # 进入 search 推荐集；identity 可标 active
```

| 规则 | 说明 |
|------|------|
| 任一步失败 | **不推进**；学 semantic-release「失败不发」 |
| 同 `id` | 发布队列串行（CI/Tekton），禁止并行写同一指针 |
| search 推荐集 | **仅** `indexed_active` 且 `identity.status=active` |
| `get_sample` | 要求 `sampleTestsPassed=true` 且状态 ≥ `samples_passed` |
| `yanked` | 立即出倒排；`get_*` 拒绝；已锁定子项强制停编码；Gate 红 |
| `experimental` | 可检索（单独策略），锁定前必人确认 + 豁免；生产分支 Gate 默认拒 |
| `deprecated` | 必填 `sunset`、`migrateTo`（`migrateTo` 可空则不得标 deprecated）；search 默认排除 |

### 4.2 `active` 硬条件（D4）

`identity.status = active` **当且仅当**该推荐版本同时满足：

1. `gav` 非空，且 Maven `exists` 探测通过；
2. `docs_split` 成功（章目录齐全、`contentHash` 非空、无空哈希上架）；
3. 样例 CI 全绿（`sampleTestsPassed=true`，`sampleTag == version`，发布快照已上传）。

缺一：最多 `experimental`，**不得超过** `active`。仅文档无制品 → 不得锁定为编码依赖。

### 4.3 拆章与 Docsify

| 项 | 设计 |
|----|------|
| 输入 | Docsify **源 md 同 commit**（不依赖运行时 HTTP GET 文档站） |
| 映射 | 一页一身份；`summary`≤80 字；tags；版本表→`versions/*.yaml`；H2→chapter；样例路径→samples 清单 |
| 图 | 不进 objects；章内须有**图意文字复述**，否则该章不得标为可编码依据 |
| 门禁 | 未重拆不得 `docs_split`；Docsify tag 与拆章 job 同 commit |
| `docsUrl` HTTP 探测失败 | **不阻断** `docs_split`；阻断「对外文档链接验收」；Agent 仍经 glue 拉已拆章 |

字符集：`id` / `version` / `chapter` 仅字母数字 `.` `_` `-`；中文在 `summary` / `title` / `tags`。`id` 发布后不改。

单章正文 > 262144 字节不得发布。空 `contentHash` **硬禁止**上架。

### 4.4 索引原子切换

1. builder 写临时对象；
2. SHA-256 + YAML 解析校验；
3. 原子改指针 `current`；
4. 失败**不切换**，保留旧快照并告警；
5. 进行中请求使用请求开始时的快照引用（volatile 局部变量）。

提供方运行时以 `search-index` 为准。**不向使用方导出常驻 index**（D3）。提供方内部可保留兼容导出供运维/备份，但不得要求装入业务仓。

### 4.5 检索质量字段

身份/版本增加（search 可过滤）：

- `category`
- `capabilities[]`
- `constraints.{jdk, springBoot, complianceTags[]}`

无版本 `get_component` 时版本列表分栏：`recommended` / `supported` / `deprecated`，不混排。服务**不**自动挑选较新版本；推荐版来自 catalog `recommended`，非「最新」。

>50 组件后再评估同义词加深（P2，不阻塞本期）。

### 4.6 企业级 HA 拓扑（默认）

| 要素 | 要求 |
|------|------|
| 存储 | `{root}` 在**共享对象存储或等价共享卷**（search-index + objects） |
| 计算 | `glue` **≥2** 无状态实例；启动拉取/watch 当前指针；进程内只读快照缓存 |
| 故障域 | Docsify 与 glue **分部署单元** |
| 入口 | 网关（APISIX/LB）：TLS、鉴权、按 token 限流、熔断 |
| 探针 | `GET /health`（进程活）；`GET /ready`（索引已加载且指针有效）——未 ready 摘流 |
| 审计 | 旁路存储，**不阻塞**查阅 |
| 禁止 | 「同机单进程」写为企业级默认 |

**RPO/RTO（书面）**：索引+objects RPO≤24h；审计 RPO≤1h；单实例故障摘流 RTO≤5min；全区域重建索引 RTO≤4h；每季度演练重建 runbook。

滚动：新实例 ready 后再接流量；双密钥版本热加载（旧 key 宽限期）；指针蓝绿切换，非「重启清内存」。

### 4.7 鉴权与协议版本

| 项 | 约定 |
|----|------|
| 头 | `Authorization: Bearer <GLUE_TOKEN>`（或企业统一网关头，实现期二选一写死） |
| 协议 | 请求/响应带 `glueProtocolVersion`（本期 `1`）；阶段包声明兼容集；不兼容 → `protocol_mismatch`，停止查阅并提问 |
| MCP ↔ HTTP | tool 名与路径一一映射（§6）；body JSON 相同 |
| 令牌 | 不进 body、不进仓库；仅环境变量 / IDE 密钥库 |

### 4.8 审计

每行字段：`ts`、`actor`、`tokenIdHash`、`scope`、`action`、`assetId`、`version`、`allowed`、`code`、`callerStage`、`clientIp?`。

保留 **180 天**；日切 jsonl + 压缩；提供方只读查询 API（按人/组件/时间）。审计不进阶段包、不参与检索。

### 4.9 错误码与 Agent/系统行为

失败响应：

```yaml
ok: false
code: ""
message: ""
glueProtocolVersion: 1
```

| code | Agent | 系统 |
|------|-------|------|
| `missing_token` / `unauthorized` | 全停查阅；不得猜 API | 审计拒绝 |
| `forbidden_stage` | 停当前调用；提示阶段 | — |
| 超时 / 5xx（可重试） | 指数退避 ≤3；仍失败 → 停该能力点（§3.4） | 网关熔断 |
| `index_not_ready` | 停查阅 | 切旧快照+告警；摘未 ready 实例 |
| `not_found` / 业务 4xx | 按 §3.3 / 各方法规则 | — |
| `sample_not_passed` / `yanked` | 不得抄样例 / 不得锁定 | — |
| `rate_limited` | 降速重试或停能力点 | 按 token QPS/日配额 |
| `protocol_mismatch` | 停查阅并提问 | — |
| glue 全不可用 | §3.4；标 `unverified` 须人批；Gate 阻断 | 运维 runbook |

### 4.10 目录布局（提供方 `{root}`）

```text
{root}/
  catalog/
    source/{id}/
      identity.yaml
      versions/{version}.yaml
      versions/{version}.chapters.yaml
      versions/{version}.samples.yaml
    built/
      search-index.yaml          # 经指针 current 引用
      current -> <snapshot-id>   # 原子指针
  objects/
    {id}/{version}/chapters/{chapter}
    references/{id}-ref/{version}/{path}
  audit/{yyyy}/{mm}/{dd}.jsonl
```

程序包**不**放进 `{root}`。

## 5. 提供方数据模型（字段级）

### 5.1 身份 `identity.yaml`

| 字段 | 约束 |
|------|------|
| `id` | 主键；与目录名相同；发布后不改 |
| `summary` | 1–80 字；倒排只切这一句 |
| `tags[]` | 每项 1–32 字，不重复 |
| `category` | 可选分类 |
| `capabilities[]` | 可选能力键 |
| `maintainer` | 可空 |
| `status` | `active` \| `experimental` \| `deprecated` \| `yanked` |

### 5.2 版本 `{version}.yaml`

| 字段 | 约束 |
|------|------|
| `gav` | `groupId:artifactId:version`；active 时非空 |
| `sampleTag` | 通过时等于 `version`，否则空 |
| `sampleTestsPassed` | bool；**仅 CI 写** |
| `docKeyTemplate` | `{root}` 相对章路径模板 |
| `packagingHint` | `starter` \| `jar` \| `bom` |
| `recommendedArtifactId` | 推荐 artifact |
| `integrationDocChapter` | 接入章 id |
| `configPrefix` | 强制 = 组件 id 或登记前缀 |
| `extensionPoints[]` | `spi` \| `spring-factories` \| `autoconfig` |
| `constraints.jdk` | 如 `>=17` |
| `constraints.springBoot` | 如 `3.x` |
| `constraints.complianceTags[]` | 合规/环境 |
| `apiCompatibility` | `compatible` \| `breaking` |
| `breaking` | bool |
| `migrationDocChapter` | 迁移章 id |
| `migrateTo` | 目标 id 或 GAV |
| `sunset` | 废弃截止日期（deprecated 必填） |
| `migrateRecipe` | 可选 OpenRewrite 坐标（二期） |
| `dependencyTreeDigest` | 可选依赖树摘要哈希 |
| `versionReleaseState` | 见 §4.1 |

### 5.3 章节目录 / 样例目录

与既有契约一致，并强化：

- 章：`chapter`、`title`、`ordinal`、`byteSize`、`contentHash`（非空）、`objectKey`
- 样例：`path`（相对、无 `..`）、`byteSize`、`objectKey = references/{id}-ref/{version}/{path}`
- 未通过测试：不要 `samples.yaml`，`sampleTestsPassed=false`

### 5.4 `search-index.yaml`

`components` = 身份 + 版本摘要。倒排：

| 倒排 | 收录 |
|------|------|
| `postings.tag` | **active** 标签 → id |
| `postings.token` | summary 切词 → id |
| `postings.deprecatedTag` | deprecated 标签 → id |
| （可选）experimental 单独集合 | 不与 active 混倒排 |

切词：去首尾空白；连续英文数字成词并小写（长<2 丢）；连续汉字相邻两字成词；标点断开。不切正文。

### 5.5 进程内五表（只读快照）

`byId` / `byVersion` / `byTag` / `byToken` / `byDeprecatedTag`。章节标题与正文不在表内。启动加载 `current` 指针指向的 index；索引切换时丢章节目录缓存（最多 256 条目录缓存，不缓存正文）。

## 6. MCP + HTTP 四方法契约摘要

### 6.1 传输

| 层 | 约定 |
|----|------|
| MCP（Agent/IDE 主入口） | 服务名 `glue`；tools：`search_components`、`get_component`、`get_doc_section`、`get_sample` |
| HTTP（同能力双暴露） | `POST /search_components` 等四路径；body = MCP arguments |
| 公共头 | `Authorization`；可选 `X-Glue-Protocol-Version: 1` |
| 成功 | `ok: true` + 方法字段 + `glueProtocolVersion` |
| 失败 | §4.9 |

完整 JSON Schema 落 `contracts/glue-lookup.md` / `glue-implementation.md`；实现开工前与本文一致齐套。

### 6.2 `search_components`

**允许阶段**：概要、详细设计（详设带概要 `id` 时做主键点查）。

**入参**：`callerStage`、`id?`、`summary?`、`tags?`、`includeDeprecated?`（默认 false）、`constraints?`（可选过滤）、`glueProtocolVersion`。

**出参**：`matches[]` 仅 `id`、`summary`、`tags`、`status`、`constraints?`；另有 `matchCount`。>20 时 `matches` 空，改 `tagFacets`。不含 gav、不含正文。

**检索步骤**（HashMap）：

1. `id` 非空 → 只查 `byId`
2. `summary` 与 `tags` 都空 → `empty_query`
3. 标签交集；summary 切词并集；两边都有再相交；仅词查询保留至少半数词命中
4. 去掉未允许 deprecated；按命中词数再 `id` 字典序
5. 应用 constraints 过滤（若提供）

### 6.3 `get_component`

**允许阶段**：详细设计、程序设计。

**入参**：`callerStage`、`id`（必填）、`version?`。

**无版本**：身份 + 分栏版本列表（含 `sampleTestsPassed`、`recommended` 标记、`constraints` 摘要）。  
**有版本**：再返回 `gav`、`docKeyTemplate`、`sampleTag`、`sampleTestsPassed`、包装/兼容字段、按 `ordinal` 的 `chapter`/`title`。不返回 `objectKey` 与正文。

服务不挑较新版本。`yanked` → 拒绝。

### 6.4 `get_doc_section`

**允许阶段**：详细设计、编码（及升级路径下的程序设计迁移章）。

**入参**：`id`、`version`、`chapter` 均必填。缺任一或要求整份文档 → 拒绝。单章 >262144 → `too_large`。

**出参**：`chapter`、`title`、`byteSize`、`contentHash`、`content`（纯文本）。读后校验哈希；不符 → `hash_mismatch`。

### 6.5 `get_sample`

**允许阶段**：编码（人已确认锁定）；测试阶段仅已锁 `testSamplePaths`。

**入参**：`id`、`version` 必填；`path?`。

| 条件 | 结果 |
|------|------|
| `sampleTestsPassed=false` | `sample_not_passed` |
| `sampleTag != version` | 拒绝 |
| `path` 空 | 只返回文件清单 |
| `path` 有 | 读发布快照单文件 |
| 单次正文合计 >1048576 | 停止；其余下次按 path |

**默认真相源**：`objects/references/{id}-ref/{version}/` 发布快照（D7）。git references **仅提供方**维护与 CI。

### 6.6 成功路径要点（编码）

1. 程序设计锁定表已写且人确认；
2. constraints 与目标工程 JDK/Boot 匹配；
3. `get_doc_section` 对照接入/差异章；
4. `get_sample` 一次规划取齐 main + test 清单，再按 path 拉取；
5. Maven 按锁定 gav 解析；
6. 只写资产未覆盖的最小胶水；可抄清单映射使用方分层；禁止 test mock 进 main。

### 6.7 失败路径要点

- 未查阅写「无」→ 评审阻断；
- 锁定前编码 → 禁止；
- 重写已点名资产 → 评审阻断级；
- 查阅不可用仍新增依赖且未标 `unverified` → Gate 红；
- BOM 顶掉 explicit version → Gate 红。

## 7. 使用方：阶段包与锁定表

### 7.1 唯一常驻入口

```text
ai-agent/
  rules/工程规约.md
  mcp/glue.md                 # 四方法契约（MCP 主入口说明 + HTTP 等价）
  agents/README.md
  skills/**/skill.md
  *公共规约.md / template/...
  （六份应用规约：已存在则安装器跳过）
```

**不得**放入阶段包：组件程序包、文档正文、样例树、glue 进程、目录索引、令牌、提供方 `specs/` / `.specify/`、IDE 整份配置。

若保留根目录 `AGENTS.md`，**仅一行指针**：「规则以 `ai-agent/rules/工程规约.md` 为准」。

### 7.2 可选安装器（非常驻入口）

复用原子写入 / 签名校验 / 幂等 / 回滚 / 退出码能力，**改写入清单为阶段包文件集**：

1. 校验阶段包签名；
2. 原子写入 `ai-agent/**`；
3. 六份应用规约已存在则跳过；
4. 写 `glueUrl` 占位、`authEnvVar=GLUE_TOKEN`、可选 IDE 本地 MCP 配置片段（**不入库**）；
5. **不写**本地 index / pin / embed；
6. 卸载只删 `managedFiles`。

升级：公共文件（rules/skills/mcp）强制更新并打 diff 报告；应用规约永不覆盖；公共文件被改脏且无 `--force` → 非 0 退出。

IDEA 插件第二期同契约。

### 7.3 程序设计锁定表（Track meta 等价物）

**不新建**平行 `.ai/tracks/**` 目录。落点：程序设计应用规约固定表，或 `ai-agent/.../lock.yaml`（实现期二选一写死，推荐独立 `lock.yaml` 供 Gate 机读）。

每行（每绑定）字段：

| 字段 | 说明 |
|------|------|
| `capabilityId` | 能力稳定键 |
| `assetId` | 组件 id |
| `version` | **定点** semver；禁 range / SNAPSHOT |
| `versionSource` | 默认 `explicit`；若必须服从 BOM 则 `bom` + `bomGav` |
| `gav` | 完整坐标 |
| `docChapters[]` | 对照章 |
| `sampleTag` | 须等于 version |
| `diffsFromSample` | 相对样例差异 |
| `testSamplePaths[]` | 测试样例路径 |
| `failureProbeGav?` | test scope |
| `contractArtifact?` | 可选契约件 |
| `completionMode` | `reuse` \| `implement` |
| `boundChapter` | 绑定章 |
| `confirmedBy` / `confirmedAt` | 人确认 |
| `stale` | bool；breaking/yanked 后标 |
| `driftClass` | 漂移六类之一或空 |
| `reuseVerification` | `verified` \| `unverified`（查阅不可用时强制） |
| `exemption?` | 见 §11 |
| `glueProtocolVersion` | 锁定时协议 |

详细设计必填能力绑定表：`capability → assetId → chapter → completionMode → exemption?`。允许**单能力**回概要重选，其它绑定保留。

人确认前不得编码。确认后不得自动换成更新版本。constraints 不满足不得锁定。

### 7.4 目录哲学

实现期常驻只认 `ai-agent/`。`.specify` = 提供方本仓章程；安装器元数据可落 `.ai/glue/init-manifest.json`（非规则正文）。禁止第三套「必须先读」规则文件。

## 8. Java 形态与 BOM / Gate

### 8.1 组件形态契约

| 项 | 要求 |
|----|------|
| `packagingHint` | starter / jar / bom；样例 pom **必须**用推荐形态 |
| 自动配置 / SPI | `extensionPoints` + 接入章写清 `scanBasePackages` / `@Import` / 排除项 |
| `configPrefix` | 上架校验 example yml；使用方禁止改组件内部前缀 |
| JDK/Boot | constraints 进 search 过滤与锁定校验；ref-ci 矩阵对齐声明下限 |
| 可抄清单 | README 映射 adapter/infra；禁 test mock 进 main |

不强制所有组件做 starter；纯 jar + `@Import` 合法，须声明。

### 8.2 BOM 与锁定（D5）

1. 锁定表默认 `versionSource: explicit`（子依赖显式 `<version>` 为准）；
2. 若必须服从 BOM：行内 `versionSource: bom` + `bomGav`；
3. Gate：构建 **resolved 依赖树** 与锁定表比对；
4. 被 BOM 覆盖且 `versionSource=explicit` → **fail**（杜绝静默顶版）；
5. 硬禁止 version range 与 `-SNAPSHOT`；
6. Renovate/Dependabot **不对** catalog 强制坐标自动升 major；
7. 建议启用 `dependencyConvergence`；未知 groupId 阻断。

### 8.3 凭证分离

| 凭证 | 用途 |
|------|------|
| `GLUE_TOKEN` | 仅查阅（MCP/HTTP） |
| Maven `settings.xml` / CI 仓凭证 | 仅拉包 |

阶段包/安装器只写占位变量名，禁止实值入库。

### 8.4 Consumer Gate 规则包（技能不能替代）

合入硬门禁（maven-enforcer + conftest/OPA 读锁定 yaml）：

1. 未知 groupId 阻断；
2. 非 catalog / 非锁定坐标不得新增；
3. deprecated/yanked 禁新用；
4. experimental 无豁免 → 生产拒；
5. **锁定表 vs resolved 树一致**（含 BOM 规则）；
6. 禁 range/SNAPSHOT；
7. 豁免块校验（§11）；
8. **`reuseVerification=unverified` 的新增依赖 → 告警；生产默认阻断**；
9. 存在未分类 `driftClass` 标记 → fail；
10. `stale` 一期 warn，试点稳定后 block。

一期：规则包（禁未知 groupId、禁手写已有 API 包名、禁大体量镜像文档目录）。指纹/AST 二期。

## 9. Reference / 样例 / 测试

### 9.1 发布快照为可抄唯一真相（D7）

```
ref-ci 绿
  → CI 服务账号上传 objects/references/{id}-ref/{version}/
  → 置 sampleTestsPassed=true、sampleTag=version
  → 允许推进 samples_passed → 后续 indexed_active
```

人工改 yaml 置位 → 下一轮覆盖或校验拒绝。Agent 默认 MCP `get_sample`。git 树仅提供方调试/开发，**非**使用方通道。

### 9.2 ref-ci 门禁（衔接 ④）

| 门禁 | 要求 |
|------|------|
| `mvn test` | 退出码 0；warm <10min 硬；cold 记基线 |
| 三版本对齐 | meta.version == jar version == docs path version |
| 密钥扫描 | 0 命中 |
| README | 可抄清单 |
| 矩阵 | 按 `constraints` / `javaVersion` 覆盖声明下限 |
| docs HTTP auth_failed | 不阻断拆章；阻断对外「可抄宣传」若依赖外链验收 |

### 9.3 测试样例迁入使用方

锁定表含 `testSamplePaths[]`。编码阶段规划一次取齐 main+test。测试阶段仅允许按已锁 id+version 补拉 test 路径。

**`sampleTestsPassed` ≠ 使用方绿**：使用方编码后必须本仓 `mvn test`。

资产内部测试不算本服务通过。须验证资产成功与失败路径（失败注入：test-scope 桩 / Testcontainers；禁止改组件源码）。可选契约件（优先 Pact-JVM）。

### 9.4 reference 仓形态

组件数 ≤20：单体仓 `references/<id>-ref`。>20 再拆仓；拆仓后 index `reference.repo`+`ref` 必填；**objects 路径约定不变**。

## 10. 漂移与查阅降级标注

### 10.1 漂移六类

规格保持事实来源。不得按代码差异回写规格，不得另建同步轨迹。继续编码前 / 交付前分类；未分类则继续编码次数为 0。比较范围：该写入位置 + 依赖声明。

| 类别 | 去向 |
|------|------|
| 仅代码偏离 | 改代码，规格不变 |
| 方法、目标工程或资产版本变化 | 程序设计作废，编码停止 |
| 字段、状态、错误码或步骤顺序变化 | 先回详细设计，程序设计作废 |
| 范围、验收、优先级或受影响服务变化 | 需求确认和架构师确认作废，已有测试通过作废 |
| 公共用法被破坏 | 按结构变更回概要 |
| 无法判断 | 停止，只问一个问题 |

`driftClass` 写入锁定旁路字段；Gate 见未分类 → fail。

### 10.2 未验证复用（D3）

| 字段/动作 | 规则 |
|-----------|------|
| `reuseVerification: unverified` | 查阅不可用期间人仍引入的依赖必须标注 |
| 技能 | 标注未验证；不得声称已 search/已对照章节 |
| Gate | 告警；生产合入默认阻断；解除须有效豁免块或恢复查阅后重验为 `verified` |

## 11. 豁免（D6）

机读块（子项完成方式固定结构）：

```yaml
exemption:
  reason: ""           # 必填
  approver: ""         # 必填
  expiresAt: ""        # ISO8601 必填
  scope: ""            # 作用域必填
  capabilityId: ""     # 对应能力必填
```

| 规则 | 说明 |
|------|------|
| Gate 只认该块 | 对话/MR 口说无效 |
| 过期或缺失 | 按强制复用失败 |
| experimental 进生产 | 必须有未过期豁免 |
| 未验证依赖放行 | 必须有未过期豁免且 reason 标明查阅不可用 |

实现：CI 读锁定 yaml 跑 conftest/OPA 策略。

## 12. 安全令牌

| 项 | 设计 |
|----|------|
| 签发 | IAM（Keycloak 或现网）；短效；scope=`glue:read` |
| CI | 短效 token，与本地个人分离 |

## 13. 落地路线图 V0–Vn

| 版本 | 竖切交付 | 验收一句话 |
|------|----------|------------|
| **V0** | 本文决策固化进阶段包技能句；意图枚举 + 工具守卫矩阵；废止本地 index / 双入口叙述 | 评测覆盖 add/upgrade/replace/bom_bump；未分类不得编码 |
| **V1** | 上架状态机 + 索引原子切换 + active 三条件；ref-ci → objects 上传衔接 | 半成品不可 search；缺样例绿不得 active |
| **V2** | glue ≥2 实例 + 共享 `{root}` + `/ready` + Docsify 分域 + MCP 适配 + HTTP 双暴露 + 错误码矩阵 | 杀一实例查阅仍可用；MCP/HTTP 同 body 互通 |
| **V3** | 阶段包安装器（仅写入 `ai-agent/`）+ 锁定表落点 | 空仓 init 后无第二套宪法、无本地 index |
| **V4** | Consumer Gate（enforcer + 锁定 vs 树 + 豁免 + unverified） | 跳过 Agent 直接 MR → CI 红；BOM 顶版 → 红 |
| **V5** | Java 形态字段 + constraints 过滤 + 样例形态校验 | Boot 矩阵不匹配无法锁定 |
| **V6** | 测试样例迁入 + 契约/失败注入约定 | 编码取齐 main+test；本仓 mvn test 必跑 |
| **V7** | 令牌生命周期 + 审计查询 180 天 | 短效 CI token；吊销生效 |
| **V8** | yanked、重建演练、阶段包升级 diff、限流滚动、签名加项 | runbook 演练通过；升级出 diff 且应用规约不被覆盖 |

**顺序**：V0 决策与意图 → V1/V2 提供方主路径 HA 与 MCP/HTTP → V3 使用方入口归一 → V4 合入硬门禁 → 再形态/测试/令牌。

实现开工前补齐：四方法 JSON Schema、阶段×方法矩阵机读版、错误码表、鉴权头、`glueProtocolVersion` 兼容矩阵。
