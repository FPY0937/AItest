## 文首原则（用户已确认，全文默认）

1. **企业级完整高可用**：查阅服务按多实例 / 共享索引 / 故障域分离设计，禁止以「单机过渡砍配」作为默认拓扑。
2. **查阅服务 HTTP±MCP 为主路径**：Agent 发现与拉章走 glue HTTP（MCP 为 IDE 适配层，可同发或后置）；**本地全量 index 进业务仓仅作灾备/弱网降级**，非默认。
3. **不全量灌使用方代码库**：业务仓只留阶段包常驻入口 + 可选 pin + 程序设计锁定表；文档正文 / reference 树 / search-index 留在提供方。
4. **触发覆盖进程内 / 升级 / 替换等**：不得仅「新服务或新系统间调用」才 `search_components`。
5. **待优化项收齐后再统一改设计正文**：本文只给更优实现方案与落地归属；正式改《规格驱动与资产复用 详细设计》等正文待主入口按本清单收口后统一开写。

### 2.2 边界一句话

| 界 | 负责 | 不负责 |
|----|------|--------|
| **提供方** | 制品、版本文档、拆章索引、样例对象、glue HA、令牌、上架状态机、导出 pin | 替业务写代码；把全站文档打进业务仓 |
| **使用方** | 装阶段包、写规格/锁定表、出胶水、跑 Gate | 私自拷过期文档；绕过坐标贴源码 |
| **Agent** | 按意图门禁调四方法；抄样例→引 GAV→最小胶水 | 静默改 acceptance；自动升 major；跳过查阅写「无」 |

### 2.3 默认数据流（主路径）

```
发布：Docsify tag → 拆章 → Maven exists → ref-ci 绿 → 上传 objects
     → 状态推进至 indexed_active → 原子切换 search-index → 导出 index.yaml(pin)
查阅：IDE Agent →（MCP 可选）→ HTTP 四方法 → 网关鉴权 → glue-http 读共享快照
编码：锁定表机读 → get_doc_section / get_sample → 私有 Maven 取包（鉴权与 GLUE_TOKEN 分离）
合入：Gate 读锁定表 + resolved 树 + exemption → 不一致则红
灾备：glue 全挂时 → pin 缓存的 index + 已锁章节本地缓存（须 Trace 失效时间）；禁止静默猜 API
```

| 列 | 内容 |
|----|------|

### B. 意图分类与检索触发

#### B1. 意图枚举与门禁矩阵（取代「仅新服务」）

| 列 | 内容 |
|----|------|
| 现状 | 概要仅在「新服务/新系统间调用」前 search；进程内不算。用户已确认过死。 |
| 问题/风险 | 架空 G1；进程内复用系统性漏检。 |
| **更优实现** | 子项机读字段 `intent` 必填，未分类不得进入可查阅阶段： |

| intent | 查阅动作 | 人确认 | 失败边界 |
|--------|----------|--------|----------|
| `add_capability` | **必须** search | 0/1/2–20/ >20 同现规则 | 停**该能力点** |
| `new_service_or_call` | 必须 search | 同上 | 同上 |
| `upgrade_existing` | **不**按能力 search；`get_component(已知 id)`；读 `breaking`/`migrateTo` | breaking 必人批+迁文档 | 停升级点 |
| `replace_capability` | 必须 search + 迁移目标确认 | 禁止当技术变更 | 停替换 |
| `bom_bump` | catalog 内坐标 **diff**→影响面清单 | 按清单拆升级子项 | 无 diff 则人工清单 |
| `in_range_change` | 不 search | — | **不得**用于「拟复用却查阅失败」 |

技能句写入概要/详细设计：进入前先写 `intent`；凡∈{add,replace,new_service} 必须完成查阅门禁。 |
| 优先级 | **P0** / ⑥阶段包 + ①文档 |

#### B2. 「新」的判定单位

| 列 | 内容 |
|----|------|
| 现状 | 「新」对照应用架构；一子项一目标工程。 |
| 问题/风险 | Maven module 新增被误判新服务，或反之漏判。 |
| **更优实现** | 判定单位=**对外可部署服务/进程**，≠ Maven module。仅新增 module 默认不触发 search，除非新暴露接口或 `add_capability`。子项可列「模块列表」，但 intent 仍按可部署单元。 |
| 优先级 | **P0** / ⑥阶段包 |

#### B3. 扩触发后查阅失败边界

| 列 | 内容 |
|----|------|
| 现状 | 地址缺失/失败：停新服务；范围内改动可继续。 |
| 问题/风险 | 扩触发后「范围内继续」变成绕过复用的洞。 |
| **更优实现** | **凡 intent 要求查阅的能力点，查阅失败一律停该能力点**；真正 `in_range_change` 才可继续。错误码矩阵见 D5。禁止用「范围内」话术跳过 `add/replace/upgrade/new_service`。 |
| 优先级 | **P0** / ⑥阶段包 + ③查阅/glue |

#### B4. 必须复用清单 vs search 冲突

| 列 | 内容 |
|----|------|
| 现状 | 2–20 问人；必须复用另开治理；冲突协议未写。 |
| 问题/风险 | Agent 静默改选或双记。 |
| **更优实现** | 应用规约「必须复用」清单 **优先于** search 排序；冲突 → 停问人，不得静默覆盖。允许提治理工单建议升格，**禁止**程序设计回写规约。 |
| 优先级 | **P0** / ⑥阶段包 + H |

#### B5. 需求阶段能力草稿

| 列 | 内容 |
|----|------|
| 现状 | 需求不得选定资产。 |
| 问题/风险 | 需求写 GAV 被当选定；或过虚导致检索词飘。 |
| **更优实现** | 需求允许「能力域/约束」标签草稿（非 id/GAV）；合规标签进身份过滤（见 C6）。禁止需求写组件 id/GAV。 |
| 优先级 | **P1** / ⑥阶段包 |

#### B6. BOM bump 影响面

| 列 | 内容 |
|----|------|
| 现状 | 技术变更含升级依赖；不 search。 |
| 问题/风险 | 抬高十几个内部组件无分类。 |
| **更优实现** | `bom_bump`：提供方或 Gate 工具对 catalog 坐标做 effective POM diff，产出升级子项清单；每项再走 `upgrade_existing`。 |
| 优先级 | **P1** / ⑤gate + ③查阅/glue |

### C. Catalog / 索引 / 拆章 / 上架状态机

#### C1. 上架跨链状态机

| 列 | 内容 |
|----|------|
| 现状 | 各步骤有描述；无统一状态。审核/分析已点。 |
| 问题/风险 | Agent 锁到半成品（有 jar 无章、有章无样例）。 |
| **更优实现** | 版本机读状态（仅 CI/发布账号可写）：`draft → artifacts_published → docs_split → samples_passed → indexed_active`。**仅 `indexed_active` 进 search 推荐集**；`get_sample` 要求 ≥`samples_passed`。任一步失败不推进。编排：同 `id` 发布队列串行（CI 或 Tekton）；学 semantic-release「失败不发」。`yanked` 立即出倒排并通知已锁定子项（见 K）。 |
| 优先级 | **P0** / ③查阅/glue + ④reference |

#### C2. active / gav 空 / 三件套

| 列 | 内容 |
|----|------|
| 现状 | 新设计 gav 可空且可 active；SSOT D11 三件套缺一不可 active。 |
| 问题/风险 | 无制品却被锁依赖。 |
| **更优实现** | `status=active`（可推荐引用）**要求**：`gav` 非空 **且** `docs_split` 成功 **且** Maven `exists` 探测通过。宣称可抄 ⇔ `sampleTestsPassed=true`（仅 CI 置位）。仅文档无制品 → 最多 `experimental`，Gate/技能不得锁定为编码依赖。 |
| 优先级 | **P0** / ③查阅/glue |

#### C3. 索引原子切换与校验

| 列 | 内容 |
|----|------|

## 5. 统一落地路线图（V0–Vn）

| 版本 | 竖切交付 | 验收一句话 | 主归属 |
|------|----------|------------|--------|
| **V0** | 决策变更文首（C1/C2/C4）+ 意图枚举技能句 + 工具守卫矩阵 | 评测用例覆盖 add/upgrade/replace；未分类不得编码 | ①⑥ |
| **V1** | 上架状态机 + 索引原子切换 + 导出 pin index + active/可抄条件 | 半成品不可 search；切换失败保留旧索引 | ③④ |
| **V2** | glue-http ≥2 实例 + 共享 `{root}` + `/ready` + 与 Docsify 分域 + 错误码矩阵 | 杀一实例查阅仍可用；同机双挂不再默认 | ③ |
| **V3** | 阶段包安装器（原 ② 改造）+ 单一常驻入口 | 空仓 init 后仅 `ai-agent/` 主规则；无第二套宪法冲突 | ②⑥ |
| **V4** | Consumer Gate（enforcer+锁定表+豁免块） | 跳过 Agent 直接 MR → CI 红 | ⑤ |
| **V5** | Java 形态字段 + constraints 过滤 + 样例形态校验 | Boot 矩阵不匹配无法锁定 | ③④ |
| **V6** | 测试样例迁入 + 契约/失败注入约定 | 编码一次取齐 main+test；本仓 mvn test 必跑 | ④⑥ |
| **V7** | 令牌生命周期 + 审计查询 180 天 + 可选 ACL | 短效 CI token；吊销生效 | ③ |
| **V8** | yanked、灾备演练、阶段包升级 diff、限流滚动、签名加项 | runbook 演练通过；升级出 diff 且应用规约不被覆盖 | ③②⑤ |

**刻意顺序**：先 V0 决策与意图（否则编码返工）→ V1/V2 提供方主路径 HA → V3 使用方入口归一 → V4 合入硬门禁 → 再形态/测试/令牌完善。

**统一改设计正文的时机**：V0 拍板完成后，按本文清单一次性修订《规格驱动与资产复用 详细设计》+ ②/④ 补丁节 + 契约齐套；然后再授权大规模实现。
